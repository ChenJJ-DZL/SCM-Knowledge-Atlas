## 这是什么

一份为 **供应链管理新人** 系统梳理的学习手册，内容综合自 **刘宝红（Bob Liu）** 在「供应链管理专栏」（scm-blog.com）的公开文章与内容。

从「供应链到底是什么」讲起，逐步拆解三道防线、降本三台阶、采购五阶段等核心方法论，用真实企业案例和核心模型串起供应链管理的完整知识体系。

## 关于作者

刘宝红（Bob Liu），旅美供应链专家，畅销书作者，西斯国际执行总监。毕业于亚利桑那州立大学供应链管理MBA。2005年创办「供应链管理专栏」（scm-blog.com），坚持原创写作，年访问量数百万人次。

著有"供应链实践者丛书"6本，由机械工业出版社出版，包括《采购与供应链管理：一个实践者的角度》《供应链的三道防线》《供应链管理：高成本、高库存、重资产的解决方案》等畅销书。
